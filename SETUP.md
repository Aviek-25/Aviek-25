# Setup instructions

1. Use the repository named `Aviek-25` under your GitHub account. Its URL should be `https://github.com/Aviek-25/Aviek-25`.
2. Extract this ZIP and upload the files inside the version folder to the repository root.
3. Preserve the `.github/workflows/snake.yml` path.
4. Commit to the `main` branch.
5. Open **Actions**, select **Generate Contribution Snake**, and click **Run workflow**.
6. If publishing the `output` branch fails, open **Settings → Actions → General → Workflow permissions**, enable **Read and write permissions**, save, and rerun.
7. The README includes local SVG project preview cards. GitHub stats and snake graphics rely on external services/workflow execution.
